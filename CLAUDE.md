## RULE ZERO — never make anything up
Every fact in copy (names, places, dates, cultivars, awards, numbers, methods, tasting notes, pairings) must come from the supplier's own material, the client, or a source verified in this session. Unverified = remove it, don't soften it, don't guess. When trimming or condensing, only cut and rephrase what's already there — never add new claims. If unsure, ask. The client should never have to repeat this.
